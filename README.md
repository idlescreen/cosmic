# IdleScreen COSMIC Applet (`idle-cosmic`)

Official System76 **COSMIC Desktop Environment** panel applet for **[IdleScreen](https://idlescreen.github.io)**.

Website: **[https://idlescreen.github.io](https://idlescreen.github.io)**

---

## ⚡ Quick Install

```bash
curl -fsSL https://idlescreen.github.io/packages/install.sh | sh
```

Or install directly via DNF on COSMIC DE:

```bash
sudo dnf install idlescreen
```
*(On COSMIC DE systems, DNF automatically installs `idle-cosmic` via package supplements).*

---

## 🪐 COSMIC Panel Integration

`idle-cosmic` adds a sleek panel applet to your COSMIC Panel:
- 1-click toggle to enable or disable screensaver engine.
- Instant screensaver preview selector.
- Live status indicator communicating with `idle-daemon` over D-Bus.
