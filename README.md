# idle-cosmic

COSMIC Desktop Environment **panel applet** for IdleScreen.

This package is the applet only (not the full stack). Install the ambient suite first (`idlescreen` / `install.sh`), then:

```bash
sudo dnf install idle-cosmic   # or: sudo apt install idle-cosmic
```

Website: [https://idlescreen.github.io](https://idlescreen.github.io)
